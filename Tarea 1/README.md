Para esta tarea, se tomó la decición de crear múltiples archivos de tipo 'html' y 'js'. Esto es con la intención de majorar la organización y legibilidad del código. Gran parte de estos códigos pueden ser creados con la misma función dentro de un mismo documento 'html' con un único código 'js', pero esto agreaga mucho "volumen", por lo que prefiero dividirlo en múltiples archivos.

En este caso 'MemberRegistration' y 'ActivityForm', tienen dos archivos 'js' para cada uno. Estos se encargan de rellenar los campos de los formularios que contienen opciones de los campos de selección (los que no usan imput) y de la validación de los campos de cada formulario. 

Para el formato de validación y de los formularios se tomó inspiración en el ejemplo visto durante el auxiliar #3, el cual pudo usarse como base para implementar los formularios y sistemas de validación en esta tarea. Además, se crearon datos para la creación de la tabla vista dentro de 'MembersList' y para graficar dentro de 'GraphData'.

Finalmente, para el estilo de las páginas, se utilizó el archivo 'styles.css' compartido en la clase auxiliar #3 y se expandió sobre lo ya existente.
